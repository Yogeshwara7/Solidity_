# Solidity Examples Collection

This repository contains a set of small Solidity example contracts used to demonstrate common language features, patterns, and learning exercises.

## Files Overview

- `Array.sol`: examples of array usage and manipulation.
- `Assert.sol`: assertions and basic testing helpers.
- `Assignment.sol`: fundamental assignment operations and patterns.
- `Auction.sol`: a basic auction contract demonstrating bidding and state handling.
- `Conversion.sol`: type conversions and numeric handling.
- `Enum.sol`: use of enums for state and option modeling.
- `FallBack.sol`: demonstration of the fallback and receive functions.
- `Mappings.sol`: examples of `mapping` usage for storage and lookup.
- `Modifiers.sol`: custom function modifiers for access and preconditions.
- `OracleAssigment.sol`: a simple oracle interaction example (external data integration).
- `Owner.sol`: ownership pattern and access control utilities.
- `Owner2.sol`: alternate ownership/access-control variant.
- `Struct.sol`: struct definitions and examples of storing complex types.
- `UniswapPair.sol`: simplified Uniswap pair-like contract demonstrating liquidity/pair concepts.
- `ViewPure.sol`: examples of `view` and `pure` function usage.
- `VisibilityAssignment.sol`: visibility specifiers (`public`, `private`, `internal`, `external`) examples.
- `Withdraw.sol`: withdrawal pattern and secure funds transfer examples.

## Conclusion

This collection is a compact learning set covering Solidity fundamentals (types, arrays, mappings, structs, enums), function features (`view`, `pure`, visibility, modifiers), common patterns (ownership, withdrawal, fallback), and small dApp-style examples (auction, oracle, Uniswap pair). It is intended as a hands-on reference for experimenting with and understanding core Solidity concepts.
